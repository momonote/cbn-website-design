# cbn网站设计案例

PrettyUp 视频人像美化工具官网 —— 单页静态站点，由设计稿直接导出还原。

## 在线预览

https://momonote.github.io/cbn-website-design/

## 双语

导航栏右上角「中文 / EN」切换，中英全套共 108 条文案。选择记入 `localStorage`（键名 `pu-lang`），首次访问按浏览器语言自动判断。英文版对标题字号、副标题宽度做了排版适配。

## 页面结构

导航 → Hero 主视觉 → AI 逐帧精修 → 美颜模板 → 肤质与脸型分析 → 更多功能 → 创作者案例 → 用户评价 → 常见问题 → 页脚

## 设计令牌

| 用途 | 色值 |
| --- | --- |
| 主色 | `#8E7CC9` |
| 深色按钮 / 页脚 | `#453C6E` / `#3A3460` |
| 墨色文字 | `#1A1626` |
| 辅助文字 | `#6B6580` |
| 区块底色 | `#F7F5FC` |
| 星级 | `#D9B871` |

字体：Poppins（英文、数字）+ Noto Sans SC（中文正文）。

## 运行

无构建依赖，直接双击 `index.html` 即可打开。图片素材在 `assets/` 目录，共 19 张。
